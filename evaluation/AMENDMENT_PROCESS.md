# Preregistration Amendment Process

1. Copy current locked files into `evaluation/amendments/<UTC_TIMESTAMP>/` before any change.
2. Record reason, proposer, prior primary lock SHA, and affected analysis.
3. Update PRIMARY_OUTCOME_LOCK.json; recompute lock_sha256 and manifests.
4. Never delete the prior freeze artifacts.
5. Amendments after Gate 3 data inspection must be labeled post-hoc and cannot claim pre-registered status for changed elements.
