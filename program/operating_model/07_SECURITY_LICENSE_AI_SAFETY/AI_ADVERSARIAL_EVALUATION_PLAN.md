# gunnchAI Adversarial Evaluation

Required categories:
- hallucination
- prompt injection
- indirect prompt injection
- tool injection
- memory poisoning
- malicious document instructions
- cross-project/user leakage
- private-data exfiltration
- unsafe computer actions
- incorrect citations
- false scientific attribution
- overconfident tutoring
- bad code modification
- connector credential leakage
- approval bypass
- scheduled-task abuse

Each case records attack ID, expected safe behavior, actual behavior, severity, evidence, fix, regression.

High-impact agent actions require V1 independent verification.
