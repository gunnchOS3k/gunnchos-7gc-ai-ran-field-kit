# Independent Security Red Team

Before field pilot:
- threat model refresh
- static analysis
- SBOM/dependency scans
- secret scanning
- parser/service fuzzing
- permission/sandbox abuse tests
- update/rollback tamper tests
- identity/session abuse
- AI-agent privilege boundary
- network-service hardening

Priority surfaces:
secure boot/update, identity, package install, AI tools/agents, connectors, MDM, continuity/fabric, Rings, network stack, game/social services.

If resources permit, commission external review before broad deployment.

Critical S0/S1 security findings block pilot.
