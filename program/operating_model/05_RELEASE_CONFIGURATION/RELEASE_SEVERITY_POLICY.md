# Release-Blocking Severity

| Severity | Definition |
|---|---|
| S0 | Safety/security/privacy catastrophe or data corruption/loss |
| S1 | Core user journey impossible |
| S2 | Major degraded product experience / serious workaround |
| S3 | Minor defect |
| S4 | Cosmetic |

EVT:
- S0 = 0
- critical design S1 = 0

Beta:
- S0 = 0
- S1 = 0

RC:
- S0 = 0
- S1 = 0
- strict S2 threshold

Field pilot:
- no unresolved S0/S1
- support/recovery/privacy/security ready
