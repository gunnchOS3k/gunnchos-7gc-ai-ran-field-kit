# Physical / External Handoff

When local digital work is exhausted, use:
- PHYSICAL_PENDING
- EXTERNAL_PENDING

Physical: battery, thermal, RF, Dock SI, Ring pose accuracy, input latency, physical FPS.
External: human study, certification lab, carrier, vendor DFM, NDA collateral, competitor-provider access.

Each pending item must have owner, exact next action, required input, acceptance evidence, expected decision.
