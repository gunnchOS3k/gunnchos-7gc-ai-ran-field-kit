# Product Quality Gate

Functional PASS is necessary but insufficient.

Score 0–4:
- 0 broken/unusable
- 1 major friction
- 2 acceptable but immature
- 3 strong production quality
- 4 excellent/preference-leading

Dimensions:
1. correctness
2. reliability
3. latency/perceived performance
4. visual quality
5. interaction quality
6. discoverability
7. consistency
8. accessibility
9. error recovery
10. user preference

Release thresholds:
- EVT software: no 0 on Golden Journeys
- Beta: average ≥2.5 and no critical dimension below 2
- RC: average ≥3.0 and no Golden Journey critical dimension below 3 without exception

Games also score feel, readability, animation/audio feedback, input responsiveness, and progression clarity.
