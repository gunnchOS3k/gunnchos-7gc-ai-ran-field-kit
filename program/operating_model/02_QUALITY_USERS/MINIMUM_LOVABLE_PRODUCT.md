# Minimum Lovable Product

Primary school computer for a full school day: real office/browser/communication, offline work, local AI, accessibility, dock, media/games, safe update/recovery.

## DS-XL Coder
Real local build/test/debug/deploy with two useful screens, AI help, ordinary office/student work, and recreation.

## Handheld Hybrid
High-quality gaming, checkpoint/resume, communication/AI, offline use, real docked work mode, continuity, safe undock.

## Rings
Reliable system input option with clear targeting/confidence; typing, pointer, shortcuts and gaming; safe conventional-input fallback.

## Dock
Power, displays, Ethernet, USB and audio with clean mobile↔workstation transitions.

## Ecosystem
Devices behave like one personal computing fabric rather than unrelated prototypes.
