# Capability Depth Ladder

| Depth | Meaning |
|---|---|
| D0 | Requirement |
| D1 | Interface/schema |
| D2 | Implementation |
| D3 | Component test |
| D4 | Integrated service |
| D5 | Actual application/runtime |
| D6 | Cross-app real user workflow |
| D7 | Target hardware |
| D8 | Sustained real-world use |

After requirements are complete, prefer moving important capabilities deeper over adding adjacent shallow breadth.
