# Cellular modem
Status: ACCEPTED

## Decision
Use RM520N-GL as Sub-6 5G baseline; no NTN/6G inference.

## Consequences
Automation must preserve this decision unless the revisit trigger is met.

## Revisit trigger
Carrier/NTN/certification/band requirements change.

## Supersession
Any incompatible Class E change requires a new/superseding ADR.
