# Field Telemetry and Feedback

Collect only necessary operational evidence:
- crashes
- update failures
- performance counters
- connectivity failures
- battery/thermal summaries
- app/game launch failures
- Ring confidence/error
- support incidents

Privacy:
- minimize/redact/aggregate
- no AI conversation content by default
- no student/private document content by default

Loop:
```text
field signal → triage → defect/risk/unknown → priority engine
→ work packet → implement/verify → release
```

Operational claims require E8.
