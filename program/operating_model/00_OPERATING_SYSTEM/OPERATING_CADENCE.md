# Operating Cadence

## Continuous
- CI on each PR
- relevant Golden Journeys on major PRs
- owner-repo evidence on promotions
- risk/unknown updates when facts change

## Twice weekly
- backlog triage
- rerank top 10
- confirm WIP ≤ 3
- close stale work packets

## Weekly
- accepted-main health report
- full Golden Journey run
- risk burn-down
- supply/license/security deltas
- EVT/external action state

## Before hardware order
- freeze release configuration
- pin SHAs/hashes/BOM/CAD/PCB
- independent NPI package check
- cost/risk review
- Edmund explicit authorization

## Before EVT
- S0 = 0
- critical design S1 = 0
- objectives and test plan ready
- fixtures/instruments ready
- evidence location ready
