# Economic Release Gate

Per device model:
BOM, PCBA, mechanical, display/touch, battery, RF, assembly, test, yield loss, NRE amortization, packaging, freight, duties, warranty/repair reserve, cloud/AI, software maintenance, support, channel.

Outputs:
COGS, landed cost, MSRP, school price, gross margin, repair cost, warranty exposure, lifetime support cost.

Before PVT:
- real quote-backed inputs where available
- dated assumptions
- sensitivity analysis
- affordability target approved
- gross-margin decision approved

No invented production pricing.
