# ADR-GAME-AR-001 — Archive of Life launch content + data tiers

- Status: ACCEPTED
- Date: 2026-08-08T00:10:52Z

## Decision
- Tier R: scalable import of known taxa (COL/GBIF/PBDB…) — fixtures ≠ global integration
- Tier E: encounter templates for supported biomes/time layers
- Tier F: flagship authored set — propose **24** flagship taxa/expeditions for launch (not all taxa)
- World: multi-biome + deep-time layers; forbid one-region-as-done
