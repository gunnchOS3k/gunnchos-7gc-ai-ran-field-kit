# ADR-GAME-PP-001 — Pedestrian Pursuit launch content scope

- Status: ACCEPTED (full-product baseline)
- Date: 2026-08-08T00:10:52Z

## Decision
- Launch racers: **8** minimum distinct
- Launch tracks: **8** across ≥2 cups (forbid 1-track done)
- Footwear/loadouts: ≥4
- Items with counterplay: full documented set
- Modes: Quick Race, Cup, Time Trial/Ghost, Local MP; Online if in final scope with client complete
See GAME_PORTFOLIO_GAP_AUDIT.md for current counts.
