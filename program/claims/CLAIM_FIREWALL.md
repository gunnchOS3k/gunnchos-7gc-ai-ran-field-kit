# Claim Firewall
Reject forbidden phrases unless evidence permits. See scripts/validate_claim_firewall.py.
Forbidden: carrier-grade deployed; 6G certified; IMT-2030 compliant; production manufacturing;
carrier accepted; FCC/CE certified; pilot validated; field proven; real battery measurement;
real thermal measurement; physical ring validated; secure boot physically validated; GATE_8_PASS.
Allowed: designed for; candidate; prototype architecture; simulation; modeled; development build;
nonphysical complete; fabrication package complete; ready for physical validation;
standards mapping current as of <date>.
